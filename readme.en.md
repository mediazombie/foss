## Linux Distros

Although this overview primarily covers software alternatives to proprietary and SaaS software, an overview of alternatives to MS Windows really should not be missing here.

**Further Information:**

- Comprehensive overview of [all possible Linux distributions](https://distrowatch.com/dwres.php?resource=popularity) incl. popularity ranking
- Interesting [project](https://www.linuxfromscratch.org/lfs/) for experienced Linux users

| Link | Description |
| :--- | :--- |
| [Fedora](https://fedoraproject.org/de/) | Stable, current Linux kernel, good software packages |
| [openSUSE](https://www.opensuse.org/de/) | Tumbleweed is considered the most stable rolling release, excellent KDE integration, system backups by default |
| [Ubuntu](https://ubuntu.com/download) | Classic all-rounder with a large community |
| [Linux Mint](https://linuxmint.com/) | Beginner-friendly Linux distribution |
| [ZorinOS](https://zorin.com/) | Especially for beginners and switchers from Windows |
| [PikaOS](https://wiki.pika-os.com/de/home) | Optimized for gaming, user-friendly, and high compatibility |
| [CachyOS](https://cachyos.org/) | Extremely optimized for performance and gaming (based on Arch) |
| [Bazzite](https://bazzite.gg/) | Performance and gaming-optimized, based on Fedora, immutable (isolated core system, therefore nearly indestructible) |
| [Fedora SILVERBLUE](https://fedoraproject.org/atomic-desktops/silverblue/) | Atomic system (similar to Bazzite) but more tuned for workstation use |
| [Debian](https://www.debian.org/index.de.html) | Classic, extremely robust foundation for servers and experienced users |
| [MX Linux](https://mxlinux.org/) | Based on Debian Stable, efficient desktops with high stability and solid performance |
| [Arch](https://archlinux.org/) | Minimalist rolling-release distro - only for experienced users! |
| [NixOS](https://nixos.org/) | Reproducible, declarative, and reliable Linux system - only for experienced users! |
| [Void](https://voidlinux.org/) | Void Linux stands out as a completely independent distribution through its radical minimalism, which—thanks to the lightning-fast package manager XBPS and the systemd alternative init system runit—guarantees maximum control and performance ([tutorial](https://www.youtube.com/watch?v=kkXXWAGegUo)). |
| [Alpine](https://www.alpinelinux.org/about/) | Security-oriented, lightweight Linux distribution - more for experienced users |
| [EndeavourOS](https://endeavouros.com/) | Lightweight, Arch-based, terminal-centric distro |
| [Manjaro](https://manjaro.org/) | Somewhat controversial Arch-based distro, more comfortable setup and installation than Arch, with excellent gaming performance |
| [Pop!_OS](https://system76.com/pop) | Based on Ubuntu LTS, from hardware manufacturer System76, COSMIC desktop still somewhat immature |

### Special Linux or Linux-like Operating Systems

| Link | Description |
| :--- | :--- |

| [Kali Linux](https://www.kali.org/) | Likewise a special Linux distro for pentesting and hacking |

| [OpenBSD](https://www.openbsd.org/) | The security fortress! OpenBSD was specifically created to be the most secure operating system |
